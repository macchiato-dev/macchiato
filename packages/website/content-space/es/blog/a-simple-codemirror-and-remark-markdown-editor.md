# Un editor sencillo de Markdown con CodeMirror y Remark
- Slug: a-simple-codemirror-and-remark-markdown-editor
- Published: 2021-02-28

## Body

Traducción del [artículo original en inglés](/language/en/blog/a-simple-codemirror-and-remark-markdown-editor).

Este es un editor sencillo de Markdown con CodeMirror 6 y Remark, resaltado de sintaxis y vista previa en vivo. La versión original se escribió en React y se publicó en CodeSandbox.

Usaba hooks de React y una actualización diferida de unos cientos de milisegundos. Los componentes `CodeEditor` y `MarkdownView` eran versiones simplificadas de los utilizados en la nueva aplicación web.
