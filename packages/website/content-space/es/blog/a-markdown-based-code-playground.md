## Body

Traducción del [artículo original en inglés](/language/en/blog/a-markdown-based-code-playground).

Este es un entorno muy sencillo para escribir HTML, CSS y JavaScript dentro de bloques de código Markdown. Al modificar un bloque se actualiza la vista aislada y cada lenguaje recibe su propio resaltado.

Se parece a CodePen porque separa CSS y JavaScript del HTML, pero también a un cuaderno como [Jupyter](https://jupyter.org/) u [Observable](https://observablehq.com/). Sus piezas principales proceden de [CodeMirror 6](https://codemirror.net/6/) y [Unified](https://unifiedjs.com/).

Estamos desarrollando sandboxes y cuadernos de código para trabajar con datos y APIs. El código está en [GitHub](https://github.com/ResourcesCo) y [GitLab](https://gitlab.com/ResourcesCo).
